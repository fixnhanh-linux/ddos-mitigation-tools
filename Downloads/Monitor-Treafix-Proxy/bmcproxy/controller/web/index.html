Quy tắc IP

Chặn: IP không mở được BMC dù đã đăng nhập. Cho phép: IP vào BMC không cần đăng nhập web. Agent nhận trong ~10 giây, không cần Áp dụng.
IP / dảiLoạiPhạm viHết hạnGhi chúNgười tạo
IPSiteBMCSố lầnLý doLần cuối

Đếm theo từng request bị từ chối (1 lần mở trang chưa đăng nhập = nhiều request). Phần lớn "chưa đăng nhập" từ IP lạ là bot quét cổng. IP là địa chỉ Traefik thấy: nếu site đứng sau proxy khác (nginx, Cloudflare) thì đó là IP của proxy đó. Cần agent bản mới.

Quản trị: toàn quyền. Vận hành: mặc định đủ 10 quyền (thêm / sửa / xoá BMC, áp dụng, dò, bảo trì, link khách, xem thống kê, nhật ký, xuất CSV) ở các site được giao. Chỉ xem: xem + xuất CSV. Bấm Sửa → Quyền chi tiết để tick thêm / bỏ bớt từng quyền. Để trống phạm vi = mọi site.
Khoá tài khoản hoặc đặt ngày hết hạn để tạm ngưng quyền (vd tài khoản nhà thầu). Đặt lại mật khẩu thì người dùng phải đổi mật khẩu ở lần đăng nhập sau. Mỗi người tự bật xác thực 2 lớp ở trang Cài đặt.

Cài đặt chung cho mọi site

Từng site có thể ghi đè URL auth-token, đường dẫn chứng chỉ, log tại trang Site → Sửa.

Xác thực 2 lớp (2FA)

Khi bật, đăng nhập cần thêm mã 6 số trên điện thoại (Google Authenticator, Microsoft Authenticator, FreeOTP…). Mất điện thoại: nhờ quản trị viên tắt 2FA cho tài khoản của bạn.

Cảnh báo qua Telegram / Email

Đăng nhập bằng tài khoản công ty (Active Directory / LDAP)

Bật lên thì nhân viên đăng nhập web bằng tài khoản Windows / AD. Vai trò lấy theo nhóm AD. Tài khoản riêng của web (vd admin) vẫn đăng nhập được khi AD hỏng - nên giữ 1 tài khoản quản trị riêng để dự phòng.

Server web chưa có thư viện ldap3. Chạy trên server web: sudo apt install -y python3-ldap3 && sudo systemctl restart bmcproxy

Tên nhóm: ghi tên (CN) như BMC-Admins cách nhau dấu phẩy, hoặc DN đầy đủ mỗi dòng 1 nhóm. Mỗi lần đăng nhập, vai trò được cập nhật lại theo nhóm AD. Người không thuộc nhóm nào nhưng quản trị đã tạo sẵn (Người dùng → Thêm → loại AD) thì dùng vai trò đặt trên web.
